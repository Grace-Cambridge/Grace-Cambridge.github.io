## 🚀 How to Deploy to GitHub

You have **3 options** to push your changes:

### Option 1: Command Line (Recommended)

Open Terminal and run:

```bash
cd ~/Desktop  # or wherever you want to clone
git clone https://github.com/grace-cambridge/grace-cambridge.github.io.git
cd grace-cambridge.github.io
```

Then download all files from this chat and place them in the folder. Then:

```bash
git add .
git commit -m "Complete Linear-style redesign with new projects"
git push origin main
```

### Option 2: GitHub Web Interface

1. Go to https://github.com/grace-cambridge/grace-cambridge.github.io
2. Click "Add file" → "Upload files"
3. Download all files from this chat
4. Drag and drop them into GitHub
5. Click "Commit changes"

### Option 3: GitHub Desktop (Easiest)

1. Download GitHub Desktop if you don't have it
2. Clone your repository
3. Download all files from this chat
4. Replace files in the local folder
5. Commit and push via GitHub Desktop interface

## 🆘 Troubleshooting

**Site not updating?**
- Clear browser cache (Cmd+Shift+R on Mac, Ctrl+Shift+R on Windows)
- Wait 3-5 minutes for GitHub Pages to rebuild
- Check GitHub Actions tab for build status

**Contact form not working?**
- Verify Formspree endpoint is active
- Check spam folder for test submissions
- Ensure form action URL is correct

**PDFs not downloading?**
- Make sure files are in root directory
- Check file names match exactly in HTML
- Verify files were pushed to GitHub
